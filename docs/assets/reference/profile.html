原点は、大阪の商店街

「まいど！」が飛び交う大阪の商店街で育ちました。八百屋のおっちゃんは「今日は何しましょ？」だけでなく、「最近、元気ないな？」と体調まで気遣ってくれる。魚屋さんは「ええの入ってるで！」と自慢する一方で、「兄ちゃん、大きくなったなぁ」と成長を喜んでくれる。

そこにあったのは売買関係ではなく、互いに認め合い、成長を喜び合う、人間本来の温かなつながりでした。

社会に出て気づいたのは、どんな設備・資金・情報があっても、それを活かすのは「人」だということ。人は数字ではなく、他のあらゆる資源の価値を何倍にもする「係数」として機能する。この確信が、社名と事業の原点です。

支援で大切にしていること

先生の顔をしない（対話型）「コンサルタントが、こうです！と教えるスタイルではありません」。1つの課題を同じ側から一緒に見て、お互いの知見で解決策を共創します。まいど！の精神＝横の関係です。
行動がすべて（行動重視）「1万回分析しても、1万枚スライドを書いても、行動しなければ成果はゼロ」。行動を起こしてくれるクライアントに、全力で伴走します。
釣りを教える（自走支援）業務の代行はしません。あなた自身が再現できるスキルと手法を残すことが支援のゴール。最終的に私が不要になる状態を目指します。
