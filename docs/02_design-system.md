# 02. デザインシステム(Webデザイナー観点)

一流のコーポレートサイトは「派手さ」ではなく「精度」で差がつく。
余白・行間・コントラストの規律を守ること。ここに定義のない値を勝手に使わない。

## 1. デザイン原則

1. **静かな自信**: 装飾で語らず、タイポグラフィと余白で信頼感を作る
2. **1画面1メッセージ**: 各セクションで伝えることは1つに絞る
3. **リズム**: 余白は8pxグリッドの倍数のみ。恣意的な値(13px, 27px…)は禁止
4. **一貫性 > 新規性**: 新しいパターンを増やす前に既存コンポーネントの再利用を検討する

## 2. カラーパレット

> ブランドカラーが未定の場合の推奨初期値。`00_project-brief.md` に指定があればそちらを正とする。

```css
:root {
  /* Primary — 既存3ページから継承したブランドネイビー */
  --color-primary-900: #16304F;  /* navy-d: CTAセクション背景 */
  --color-primary-700: #1F3A5F;  /* navy: メインブランドカラー */
  --color-primary-500: #3B6BA5;
  --color-primary-100: #E8F0FA;  /* accent: 引用・強調背景 */

  /* Brand Accent — ロゴデータシート記載の正式カラー */
  --color-brand-orange: #F39800;  /* RGB 243/152/0・PANTONE 1495C・CMYK 0/50/100/0 */
  --color-brand-black:  #231816;  /* 1C(モノクロ)版ロゴの黒 */
  --color-brand-teal:   #19B4C3;  /* フルロゴのティール(logo_full.pngから実測) */
  --color-accent-600:   #D98A1F;  /* オレンジの濃色(hover等) */

  /* CV — LINEボタン専用(他の用途に使わない) */
  --color-line: #06C755;

  /* Neutral(既存ページのApple系トーンを継承) */
  --color-text: #1D1D1F;
  --color-text-muted: #6E6E73;
  --color-border: #D2D2D7;
  --color-bg: #FBFBFD;
  --color-bg-subtle: #F5F5F7;

  /* Semantic */
  --color-error: #C0392B;
  --color-success: #1E7E4A;
}
```

### 使用ルール
- CV(LINE誘導ボタン)は `--color-line` 緑のみ。サイト内で緑=申し込みの意味を固定する
- ブランドオレンジ `#F39801` は見出しマーカー・アイコン・タイムライン現在地など「注目点」に限定
- **オレンジ・ティールを本文テキスト色や白文字ボタンの背景に使わない**(白との
  コントラスト比が不足: オレンジ約2.1:1 / ティール約2.5:1)。テキストで使う場合は
  大見出しサイズ+濃色背景の上のみ。ボタンはネイビー(Primary枠/塗り)とLINE緑に限定
- ティール `#19B4C3` は罫線・区切り線・図解の補助色として控えめに。オレンジと同一画面で多用しない
- テキストと背景のコントラスト比: 本文 4.5:1 以上、大見出し 3:1 以上(必須)
- 背景色は白と `--color-bg-subtle` の交互でセクションのリズムを作る

## 2b. ロゴ使用規定

### アセット一覧(`docs/assets/logo/`)

| ファイル | 用途 |
|---|---|
| `maido_symbol_orange.svg` / `.png` | シンボル正規版(4C・#F39800)。白/淡色背景用。**Webの第一選択** |
| `maido_symbol_white.svg` / `.png` | 白抜き版。ネイビー背景(フッター・CTAセクション)用 |
| `maido_symbol_black.svg` / `.png` | 1C(モノクロ)版。印刷・特殊用途 |
| `logo_full.png` | 横組みフルロゴ「maido & crafts strategy」(オレンジ×ティール・透過PNG) |
| `source/*.ai` | 元データ(改変せず保管) |

### 使用ルール

- ヘッダー: フルロゴ(`logo_full.png`)を白背景にオリジナルカラーで、高さ32〜40px
- フッター・ネイビー背景: `maido_symbol_white.svg` + 白テキストで社名を併記
- favicon / OGP / SNSアイコン: `maido_symbol_orange`(正方形トリミング)
- 最小サイズ: フルロゴ横幅120px以下ではシンボル版に切り替え
- クリアスペース: シンボルの円の半径以上を周囲に確保
- 変形・色変更(規定3色以外)・影・グラデーション化は禁止
- SVG注記: シンボルSVGはデータシート全体をviewBoxで切り抜いた構造(表示は正常)。ファイルサイズ最適化(SVGO等)は実装時に実施可
- 未解決: `source/maido_logo_REdesing_fix__119_.ai` はPDF互換なし保存のためAdobe製品以外で開けない。フルロゴのSVG化が必要になったら、Illustratorで「PDF互換ファイルを作成」にチェックして再保存したデータの提供を依頼する

## 3. タイポグラフィ

```css
:root {
  --font-sans: -apple-system, BlinkMacSystemFont, "Hiragino Sans",
               "Hiragino Kaku Gothic ProN", "Noto Sans JP", Meiryo, sans-serif;
  /* 既存3ページのシステムフォント構成を継承(Webフォント読み込みなし=高速) */
  /* 英字見出しに使う場合: "Inter" を先頭に追加 */
}
```

### タイプスケール(1.25倍率ベース)

| 用途 | サイズ(PC) | サイズ(SP) | weight | line-height | letter-spacing |
|---|---|---|---|---|---|
| Display(トップHero) | 48px | 32px | 700 | 1.3 | 0.02em |
| H1 | 36px | 28px | 700 | 1.35 | 0.02em |
| H2 | 28px | 24px | 700 | 1.4 | 0.02em |
| H3 | 20px | 18px | 600 | 1.5 | 0.02em |
| 本文 | 16px | 16px | 400 | **1.9** | 0.03em |
| キャプション | 13px | 13px | 400 | 1.6 | 0.03em |

### 日本語組版の必須ルール
- 本文の行間は 1.8〜2.0(欧文の感覚で 1.5 にしない)
- 1行の長さ: 全角35〜42文字(`max-width: 42em` 相当)を上限
- 見出しの改行位置は意味の切れ目で制御(`<br class="sp-only">` や `text-wrap: balance`)
- **折り返しは文節単位**: `body` に `word-break: auto-phrase` を指定済み。
  「行動が変わら/ない」のように語の途中で切れるのを防ぐ
- **泣き別れを作らない**: 本文系要素に `text-wrap: pretty` を指定済み。
  最終行に1〜2文字だけ残る状態は不可(実装後に375/768/1280/1440pxで確認する)
- 短いリード文・カード見出しには `text-balance` を添えて行長を揃える
- 約物(、。「」)が行頭に来る禁則処理はブラウザ標準に任せ、無理に詰めない

## 4. スペーシング(8pxグリッド)

| トークン | 値 | 用途 |
|---|---|---|
| space-1 | 8px | 要素内の最小余白 |
| space-2 | 16px | テキスト間 |
| space-3 | 24px | カード内パディング |
| space-4 | 32px | 要素グループ間 |
| space-6 | 48px | セクション内ブロック間 |
| space-8 | 64px | セクション上下(SP) |
| space-12 | 96px | セクション上下(PC) |
| space-16 | 128px | 大セクション区切り(PC) |

**セクションの上下余白は最低でも 64px(SP)/ 96px(PC)。窮屈なコーポレートサイトは安く見える。**

## 5. レイアウト

- コンテンツ最大幅: `1120px`(テキスト主体のページは `800px`)
- 左右パディング: SP `20px` / PC `40px`
- ブレークポイント: `640px` / `768px` / `1024px`(Tailwind標準に準拠)
- グリッド: 12カラム。カード列は PC 3列 / タブレット 2列 / SP 1列 が基本

## 6. コンポーネント規定

### ボタン
- Primary(CV用): アクセントカラー背景・白文字・padding `16px 32px`・radius `6px`
- Secondary: 枠線のみ(primary-700)
- hover: 背景を1段階濃く + `transition: 0.2s ease`。拡大や派手なアニメは禁止
- 高さ44px以上(タップターゲット)

### カード
- 背景白・border `1px solid var(--color-border)`・radius `8px`・padding `24px`
- 影は `0 1px 3px rgba(0,0,0,0.06)` まで。濃いドロップシャドウ禁止

### 角丸の統一
- ボタン: 6px / カード: 8px / 画像: 8px / タグ: 4px — これ以外の値を作らない

## 7. モーション

- 原則: `opacity` と `transform` のみ。`0.2s〜0.4s ease-out`
- スクロール連動アニメは「フェードイン + 8px上昇」までの控えめなものに限定
- `prefers-reduced-motion: reduce` では全アニメーション無効化(必須)

## 8. 禁止事項(安く見える要因)

- 3色以上のグラデーション、虹色、ネオン
- 5種類以上のフォントウェイト混在
- カルーセル(自動スライド)をHeroに使うこと
- ストック素材感の強い「外国人がオフィスで握手」系画像
- パララックス・回転・バウンドなど過剰なモーション
