## 1. ページヘッダー

- H1: サービス
- リード: 「あと一歩の壁」を超えるために。再現性の高い「思考OS」と、その土台となるポータブルスキルを、教育×実践×リフレクションの循環で身につける伴走プログラムです。

## 1b. 身につけたものが、届く範囲(2026年8月28日 追加・実装済み)

- ページヘッダー内、リードの直下に罫線で区切って配置(トップページ 02「どこまでも、持ち運べる」の短縮版)
- 3段を横並びに: 目の前の仕事で → チームと組織で → キャリアと人生で。横棒の幅を 1/3 → 2/3 → 全幅 に広げ、最終段のみオレンジ
- 法人向けの一文を添える:「法人のご支援では、この変化がチームに広がり、やり方が社内に残ることを目指します。」
- **必須の注記**: 「※いずれも、プログラムを通じて目指す状態です。到達までの期間や度合いは、状況によって異なります。」

## 2. 共通の考え方(短く)

- 課題認識: ビジネスが複雑化する中、「あと一歩の壁」(仕事・キャリア・人生)を越えられない。真の原因は多くの場合、専門知識ではなくポータブルスキルの欠如
- 解決策: ボトルネックを特定し、再現性の高い「思考OS」(発言や行動のベースとなる考え方・価値観)をインストールする
- 手法: 教育 × 実践 × リフレクション / 対話型(先生の顔をしない)・行動重視・自走支援

## 3. 個人向け(ステップ式で提示)

### STEP 0: 個別相談(入口)
- 60分・3,000円・オンライン。「どこから手を付けるか」の見立てをその場で必ず渡す
- 相談だけで終えてOK。LINEで「個別相談」と送るだけ

### STEP 1: 社外参謀 1on1ブートキャンプ
- あなたの仕事とキャリアに"社外の専属参謀"が1人つく、全4回・マンツーマンの超実務プログラム
- 流れ: #1 テーマ設定 → #2 ボトルネックの特定 → #3 打ち手の検討 → #4 アクションプランの明確化(90日)
- 終了時の状態: ボトルネック / AS-IS・TO-BE / アクションプランが言語化され、「次の一歩」が明確になっている
- 対象: 経営企画・事業推進・DX推進・人事企画など問題解決を仕事にしている方 / コンサル志望者
- 特徴(4つ): 思考OSをインストール / 社外参謀スタイルのマンツーマン / 案件ベースの実践的フィードバック / スキル・マインドセットの両方を体系化
- 獲得できるもの: 戦略的思考・仮説構築力 / 構造化・論理展開力 / ファシリテーション・ヒアリング力 / 課題設定と実行PDCA + 2つのマインドセット
- 活用例2件(資料p.13の30代経営企画・30代ITコンサルの事例を要約掲載)
- **料金: お問い合わせください**(CTAを設置)

### STEP 2: 社外参謀 伴走プログラム
- ブートキャンプで構築した「思考OS」を現場実装し、目に見える成果を取りに行く長期プロジェクト
- 形式: 月2回(60分程度)の1on1 / 標準プラン3か月・ロングプラン6か月
- 期間中サポート: チャットでの相談・壁打ち(原則平日24〜48時間以内返信)
- 特徴: 現場実装に特化 / 重要会議・提案・評価面談・転職面接など「勝負どころ」の前後で壁打ち・シミュレーション
- 対象: ブートキャンプを終え「この社外参謀と半年〜1年、本気で走ってみたい」と感じた方
- **料金: お問い合わせください**

## 4. 法人向け

### チーム研修(基本パッケージ)
- 教育×実践×リフレクションによる、再現可能で持続的な成長のための包括支援(貴社の状況に合わせてカスタマイズ可能)
- 構成:
  - 00 キックオフ(必須): 心理的安全性の確保、ポータブルスキルと取り組みの狙いの説明
  - 01 ポータブルスキルワークショップ: 1〜2週間毎・全4回(現状分析、目標設定、戦略思考、問題解決、コミュニケーション、ファシリテーション等)
  - 02 プロジェクト計画書(行動計画書)作成支援
  - 03 徹底的なフォローアップ / プロジェクト遂行支援(週1回 or 隔週)
- 特徴: 3名程度の少人数・高密度 / 自走化前提のフェーズアウト設計
- **料金: お問い合わせください**

### プロジェクト伴走支援・コンサルティング
- 「はい、わかりました」とは言いません — 代行ではなく共創。ノウハウが社内に残り、自走できる状態がゴール
- 支援実績(2026年8月27日 掲載解禁済み・実装は CaseList コンポーネント): 大手企業向けシステム構想・PM/PMO支援、DX人材育成の企画・実行支援、CS立ち上げ・仕組化支援、コンサルスキル研修講座、PM人材の育成・伴走支援(自走化ゴール・フェーズアウト設計。2026年8月28日追加)、社外メンターサービス
- **料金: お問い合わせください**

## 5a. こんな方と、ご一緒しています(2026年8月28日 追加・実装済み / #fit)

- 目的: 価値観をはっきり示し、共感いただける方からの問い合わせに絞る(ミスマッチの事前解消)
- 配置: 「研修でも、コンサルでもなく」の直後、「料金について」の前
- リード: どなたにでも合う支援ではありません。私たちの考え方に納得いただけたときに、いちばん良い結果が出ます。だから、合わないかもしれない点も先にお伝えします。
- ご一緒したい方(4): 小さくても行動を起こす方 / 「できるようになる」ことを望む方 / 成長のための時間を守れる方 / まだ整理がついていない方
- 反対に、お力になれないこと(3): 業務の代行 / 答えだけをお渡しすること / 時間をまったく確保できない状況での実施
- **表現の注意**: 断定的に排除しない。既存FAQ「代行はしません」と同じ穏やかなトーンを保ち、「合わないと感じたら、そこで終わりにして大丈夫です」で締める
- 内容はすべて既存の理念(行動重視・自走支援・支援の3原則「成長のための時間を確保する」)とFAQから導いたもの。新しい方針を創作しない
- 末尾に /about/ への導線(理念とビジョン)

## 5b. 料金について(2026年8月28日 追加・実装済み / PricingPolicy コンポーネント)

- 目的: 料金非掲載サイトの最大の離脱要因である「問い合わせたら売り込まれそう」という不安を、金額を書かずに取り除く
- 掲載内容: ①一律の価格表を出さない理由(必要な支援だけを提案したいため)②お見積りが決まる3要素(期間/対象人数/関与の深さ)③問い合わせ後に催促・売り込みをしない旨 ④先に金額を伝えているのは個別相談(60分・3,000円)だけである旨
- 掲載場所: /services/#pricing(フル)、/contact/ のフォーム直前(compact 版 + フルへのリンク)
- 金額は個別相談の 60分・3,000円 以外を書かない(brief §6b)
