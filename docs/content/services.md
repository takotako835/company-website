- **価格方針(確定)**: プログラム料金は掲載しない。「料金はお問い合わせください」で統一(個別相談の60分・3,000円のみ掲載可)

## 1. ページヘッダー

- H1: サービス
- リード: 「あと一歩の壁」を超えるために。再現性の高い「思考OS」と、その土台となるポータブルスキルを、教育×実践×リフレクションの循環で身につける伴走プログラムです。

## 2. 共通の考え方(短く)

- 課題認識: ビジネスが複雑化する中、「あと一歩の壁」(仕事・キャリア・人生)を越えられない。真の原因は多くの場合、専門知識ではなくポータブルスキルの欠如
- 解決策: ボトルネックを特定し、再現性の高い「思考OS」(発言や行動のベースとなる考え方・価値観)をインストールする
- 手法: 教育 × 実践 × リフレクション / 対話型(先生の顔をしない)・行動重視・自走支援

## 3. 個人向け(ステップ式で提示)

### STEP 0: 個別相談(入口)
- 60分・3,000円・オンライン。「どこから手を付けるか」の見立てをその場で必ず渡す
- 相談だけで終えてOK。LINEで「個別相談」と送るだけ

### STEP 1: 社外参謀 1on1ブートキャンプ
- あなたの仕事とキャリアに"社外の専属参謀"が1人つく、全4回・マンツーマンの超実務プログラム
- 流れ: #1 テーマ設定 → #2 ボトルネックの特定 → #3 打ち手の検討 → #4 アクションプランの明確化(90日)
- 終了時の状態: ボトルネック / AS-IS・TO-BE / アクションプランが言語化され、「次の一歩」が明確になっている
- 対象: 経営企画・事業推進・DX推進・人事企画など問題解決を仕事にしている方 / コンサル志望者
- 特徴(4つ): 思考OSをインストール / 社外参謀スタイルのマンツーマン / 案件ベースの実践的フィードバック / スキル・マインドセットの両方を体系化
- 獲得できるもの: 戦略的思考・仮説構築力 / 構造化・論理展開力 / ファシリテーション・ヒアリング力 / 課題設定と実行PDCA + 2つのマインドセット
- 活用例2件(資料p.13の30代経営企画・30代ITコンサルの事例を要約掲載)
- **料金: お問い合わせください**(CTAを設置)

### STEP 2: 社外参謀 伴走プログラム
- ブートキャンプで構築した「思考OS」を現場実装し、目に見える成果を取りに行く長期プロジェクト
- 形式: 月2回(60分程度)の1on1 / 標準プラン3か月・ロングプラン6か月
- 期間中サポート: チャットでの相談・壁打ち(原則平日24〜48時間以内返信)
- 特徴: 現場実装に特化 / 重要会議・提案・評価面談・転職面接など「勝負どころ」の前後で壁打ち・シミュレーション
- 対象: ブートキャンプを終え「この社外参謀と半年〜1年、本気で走ってみたい」と感じた方
- **料金: お問い合わせください**
