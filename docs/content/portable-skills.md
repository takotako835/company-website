- 一次資料: docs/content/ポータブルスキル説明資料.pptx(スライド3枚)
- 2026年8月27日: レファレンスチェックを実施のうえページ実装(下記の検証結果に従う)

## レファレンスチェック結果(2026年8月27日実施)

### 掲載可(検証済み)

| 内容 | 検証結果 |
|---|---|
| 厚労省のポータブルスキル定義 | mhlw.go.jp/stf/newpage_23112.html に実在。ただし正しい文言は「職種の専門性以外に、**業種や職種が変わっても**持ち運びができる職務遂行上のスキル」。資料の「業種や環境が」は不正確 → **正しい文言で掲載** |
| 経産省「未来人材ビジョン」 | **2022年5月**公表(資料の「(2023)」は誤り)。2050年に「問題発見力」「的確な予測」「革新性」等の重要性が高まるという試算は実在 → 年を修正して掲載 |
| Deloitte スキルベース組織の調査値 | 107%(人材配置)・98%(ハイパフォーマー維持)・79%(職場体験)・63%(成果達成)・57%(俊敏さ)は実在。ただし正しくは「**そうでない組織に比べ〜の可能性が◯%高い**」。資料の「◯%の企業が成功」は誤読 → 正しい表現で掲載 |
| Deloitte スキルの可搬性(76%/55%) | deloitte.com の記事で原文確認済み → 掲載 |

## ページ構成(実装済み)

1. ヘッダー: H1 + 要約リード
2. 01 定義 — 厚労省の定義(正確な文言+出典リンク)+ 専門知識との対比(自社の解説)
3. 02 代表的なポータブルスキル(一例) — 目的・目標設定/現状分析/戦略設定/問題解決(自社の整理。効果の説明つき)
4. 03 なぜ今、重要なのか — 未来人材ビジョンの試算 + Deloitte調査(正しい「〜の可能性が◯%高い」表現・出典明記)
5. 04 私たちの考え — 価値倍増装置(company.html の資産)+ 身につけ方 → サービス/診断への導線
6. 出典一覧
7. CTA

- 導線: 会社案内「なぜポータブルスキルなのか」/ サービス「共通の考え方」/ トップ信頼カードからリンク(ヘッダーは5項目上限のため追加しない)
