# 01. ブランドガイドライン

既存3ページに強いブランド資産がすでにある。**新規に創作せず、この資産を磨いて使う。**

## 1. ブランドコア(確定)

- **経営理念**: 「人の成長が価値を倍増させる」
- **キーメッセージ**: 「人は数字ではない。しかし、数字を何倍にもする。」
- **ミッション**: 成長の土台となるポータブルスキルを構築し、個人と組織の持続的な発展を促進することで、社会に貢献できる人材を輩出する
- **ビジョン**: すべての人が自らの成長を実感し、その喜びを仕事に見出せる社会を創造する。「教育と実践の融合」で、人と組織の可能性を最大限に引き出す最高のパートナーとなる
- **行動指針(5)**: 1. 人は係数として機能することを理解する / 2. 成長の喜びを分かち合う / 3. 基礎を大切にする / 4. 実践と教育を循環させる / 5. 社会への貢献を目指す
- **持続的成長の4要素**: 想い × 誠実さ × スキル × 行動
- **中心概念**:
  - 人=「係数」: 同じ予算・設備・情報でも、成果は人で何倍にも変わる
  - 「まいど!」文化: 大阪の商店街にあった、互いの成長を喜び合う横の関係
  - ポータブルスキル: 業種・職種が変わっても持ち運べる実践的能力(厚労省定義に準拠する旨の注記を維持)

## 2. ポジショニング(差別化の核)

「研修でも、コンサルでもなく」の3列対比を全体設計の軸にする:

| | 研修会社 | コンサル会社 | **私たち** |
|---|---|---|---|
| 型 | 知識伝達型 | 問題解決型 | **個人×組織 成長伴走型** |
| 課題 | 「知る」で終わる | 代行で依存が生まれる | 自走できる状態がゴール |

- キーメタファー: 「釣った魚」ではなく「釣り方」を渡す
- 手法: 教育 × 実践 × リフレクション の循環
- サービスブランド用語(サイト全体で表記統一):
  - 「思考OS」: 発言や行動のベースとなる考え方・価値観。「再現性の高い思考OSをインストールする」
  - 「社外参謀」: 実績豊富で利害関係のない、社外の専属参謀。個人向けプログラムの提供者としての立ち位置
  - 「ポータブルスキル」: 目標設定実行力・現状分析力・問題解決力・戦略的思考力・コミュニケーション力・変化対応力など(厚労省定義への言及と出典を維持)
  - 「あと一歩の壁」: ターゲットの課題を表す言葉(仕事の壁・キャリアの壁・人生の壁)

## 3. ブランドパーソナリティ

- 性格: 商店街のおっちゃん的な温かさ × 戦略コンサル出身の論理性
- 話し方: 先生の顔をしない。断言よりも対話。ただし行動については妥協しない
- 決め台詞的な資産(既存コピーを尊重して再利用):
  - 「まず、聴かせてください」
  - 「まとまっていない相談ほど、歓迎です」
  - 「合わないと感じたら、そこで終わりにして大丈夫です」
  - 「『はい、わかりました』とは言いません」
- してはいけないこと: 売り込み感 / 上から目線 / 不安を煽る訴求 / 実績の誇張

### トーンのスペクトラム

```
フォーマル ——○●——— カジュアル(敬語だが距離は近い)
論理的     —●○————— 情緒的(構造で語り、情で結ぶ)
挑戦的     ——○●——— 堅実(行動は促すが、無理はさせない)
```

## 4. ビジュアルアイデンティティ(既存資産から確定)

- ブランドカラー: ネイビー `#1F3A5F` × サンイエロー `#F0A03C`(詳細は 02_design-system.md)
- 代表写真: `docs/assets/tamaoka.jpg`(丸型トリミングで使用実績あり)
- ロゴ: **AIデータ受領・Web用アセット生成済み** — `docs/assets/logo/` にSVG/PNG各色(オレンジ/白抜き/黒)とフルロゴを格納
  - モチーフ: 「毎」の字を図案化(=まいど)+挨拶の手+昇る太陽と地平線
- ロゴ正式カラー(データシート記載): オレンジ `#F39800`(RGB 243/152/0・PANTONE 1495C)/ ティール `#19B4C3`(フルロゴ実測)
- Webでの色構成: 信頼感のネイビーを基調に、ロゴのオレンジを「注目点」、ティールを補助色として使用(詳細は 02_design-system.md)
- 写真のトーン: 誇張のない実直なもの。ストック素材の多用は避ける
